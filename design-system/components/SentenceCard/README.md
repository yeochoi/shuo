# SentenceCard

The one thing on the main screen. The sentence you are saying now.

- White `surface` card, 1px `line` border, `radius-card`, 20 padding, at least `size-card` tall so the buttons below never move.
- Top to bottom, the count in `body` `muted`, the characters in `sentence` `ink`, pinyin in `pinyin` `accent-text`, English in `body` `muted`.
- English is optional. When it is empty the line keeps its space.
- The StatusPill sits at the bottom while playing.
