# StatusPill

Says what is happening while Play is on.

- `small` at medium weight, 30 tall, `radius-pill`.
- Listen and Listen again sit on `soft` with `accent-text` and a pulsing `primary` dot.
- Your turn is solid `primary` with white text and a still dot, so it is clear at a glance that it is time to speak.
- Hidden when Play is off. It keeps its space so the card does not jump.
