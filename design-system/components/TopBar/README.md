# TopBar

The top of the main screen.

- Shuo in `title` with 说 next to it in `font-mark`, Noto Sans SC Medium at 20 in `accent-text`. The same character and font as the icon, so the name and the icon read as one mark.
- Three `size-round` buttons on `chip` at the right. + opens New sentence, the list icon opens Sentences, the sliders icon opens Settings.
- + comes first because adding a sentence you just heard should take one tap.
- Nothing else lives here.
