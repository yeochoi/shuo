# GotIt

Moves the sentence you are on to Learned.

- White `surface` button, 1px `line` border, `size-button` tall, `title` in `accent-text` with a check.
- The note below reads Tap Got it when you can say it easily until the first one is learned, then the number learned so far.
- Tapping it shows the Toast with Undo. If Play was on, it keeps playing the next sentence.
